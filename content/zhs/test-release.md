# 测试与发布

请在公开版 BBQ Player 中测试构建包。编辑器预览无法覆盖启动加载、Cook 保留、已保存预设恢复，
以及从当前自定义根界面切换出去等情况。

## 本地测试

1. 关闭 BBQ Player。
2. 将完整构建包目录复制到 Player 的本地 Mods 目录。
3. 正常启动 Player。
4. 在包管理器中找到本地包并启用。
5. 从纯净进程重新启动。
6. 打开 Settings，在 UI 预设列表中找到 Definition 的 **Display Name**。
7. 选择它并确认根界面重新构建。
8. 再次重启并确认选择得到恢复。

## 功能矩阵

测试根界面提供的每项功能：

- 空媒体库和有内容的媒体库；
- 空队列、单项队列和重排队列；
- 播放、暂停、跳转、上一首、下一首、静音和音量；
- 当前字幕和字幕清除；
- 运行时与前景叠加层；
- 不移除叠加层的 HUD 可见性切换；
- 通知、确认、持久显示和自动关闭；
- 最小化、最大化、还原和安全关闭；
- 设置变化和 UI 预设恢复；
- 失败或不可用的 API 请求。

还应测试窄、普通、宽窗口，多种 DPI，键盘焦点，较长译文，缺少可选图片和减少动画偏好。

## 清理和回退

1. 切回标准 UI，确认自定义根界面不再收到事件。
2. 再次选择自定义根界面，确认订阅没有重复。
3. 禁用或移除该包。
4. 重启并确认启动回退到标准根界面。
5. 先安装旧版本，再更新到新包并重复选择测试。

## 发布检查清单

- [ ] 使用最新公开 BBQ UGC Tool 和要求的 Engine 版本构建。
- [ ] 所有资产均保存于 `Content/<PluginName>` 下。
- [ ] 根界面实现 `BBQUIRoot` 并分离显示图层。
- [ ] 生命周期只初始化一次，并解除所有监听。
- [ ] 完整实现通知显示，或保持其未设置。
- [ ] UI Root Definition 名称唯一稳定，并具有有效根类。
- [ ] Definition 已加入 `PluginEntry` 的 Asset Register List。
- [ ] 每个命令和完成流程都处理失败。
- [ ] 标准 UI 仍可作为恢复路径。
- [ ] 纯净安装、重启、切换、更新和回退测试均通过。
- [ ] 测试交付版本时已移除冲突的本地包。
