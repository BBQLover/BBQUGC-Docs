# 測試與發佈

請在公開版 BBQ Player 中測試建置套件。編輯器預覽無法涵蓋啟動載入、Cook 保留、已儲存預設復原，
以及從目前自訂根介面切換出去等情況。

## 本機測試

1. 關閉 BBQ Player。
2. 將完整建置套件目錄複製到 Player 的本機 Mods 目錄。
3. 正常啟動 Player。
4. 在套件管理器中找到本機套件並啟用。
5. 從乾淨程序重新啟動。
6. 開啟 Settings，在 UI 預設清單中找到 Definition 的 **Display Name**。
7. 選擇它並確認根介面重新建構。
8. 再次重新啟動並確認選擇已復原。

## 功能矩陣

測試根介面提供的每項功能：

- 空媒體庫及有內容的媒體庫；
- 空佇列、單項佇列及重新排序佇列；
- 播放、暫停、跳轉、上一首、下一首、靜音及音量；
- 目前字幕及字幕清除；
- 執行階段及前景覆疊層；
- 不移除覆疊層的 HUD 可見性切換；
- 通知、確認、持續顯示及自動關閉；
- 最小化、最大化、還原及安全關閉；
- 設定變更及 UI 預設復原；
- 失敗或不可用的 API 要求。

亦應測試窄、一般、寬視窗，多種 DPI，鍵盤焦點，較長翻譯，缺少選用圖片及減少動態效果偏好。

## 清理與回復

1. 切回標準 UI，確認自訂根介面不再收到事件。
2. 再次選擇自訂根介面，確認訂閱沒有重複。
3. 停用或移除該套件。
4. 重新啟動並確認啟動回復到標準根介面。
5. 先安裝舊版本，再更新至新套件並重複選擇測試。

## 發佈檢查清單

- [ ] 使用最新公開 BBQ UGC Tool 及要求的 Engine 版本建置。
- [ ] 所有資產均儲存於 `Content/<PluginName>` 下。
- [ ] 根介面實作 `BBQUIRoot` 並分離顯示圖層。
- [ ] 生命週期只初始化一次，並解除所有監聽。
- [ ] 完整實作通知顯示，或保持其未設定。
- [ ] UI Root Definition 名稱唯一穩定，並具有有效根類別。
- [ ] Definition 已加入 `PluginEntry` 的 Asset Register List。
- [ ] 每個命令及完成流程都處理失敗。
- [ ] 標準 UI 仍可作為復原路徑。
- [ ] 乾淨安裝、重新啟動、切換、更新及回復測試均通過。
- [ ] 測試交付版本時已移除衝突的本機套件。
