# 製作內容

1. 選擇專案並按一下 **Open Project**。
2. 將所有自製資產放在 `Content/<PluginName>/` 之下。
3. 使用目前範本公開的功能建立內容。
4. 儲存所有資產，並解決參照遺失、編譯錯誤和驗證警告。

烘焙範圍限定在外掛程式內容根目錄。即使編輯器中可以運作，放在其他位置的資產仍可能被省略。不要參照僅限編輯器的內容、本機絕對路徑、測試資產或未向創作者提供的 Player 資產。

## 選用 UI 套件

專案可以提供可選擇的替換介面。請從[建立根介面](create-root.md)開始，實作[根介面生命週期](lifecycle.md)，並且只使用文件中的 [UI API](apis.md)。

## 關閉 Unreal 前

- 儲存所有修改過的資產。
- 編譯 Blueprint 並解決錯誤。
- 確認必要參照位於支援的創作者內容中。
- 在其他內容依賴它們之前確認名稱和路徑。
