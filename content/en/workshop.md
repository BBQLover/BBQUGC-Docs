# Workshop

Keep the Workshop item private until the downloaded copy passes testing. Steam must be running with the account that owns the item, and first-time creators may need to accept the Workshop agreement.

!!! warning "Distribution terms"
    Before uploading, review and accept the [Steam Workshop Legal Agreement](https://steamcommunity.com/workshop/workshoplegalagreement/?appid=3111940), the [Steam Subscriber Agreement](https://store.steampowered.com/subscriber_agreement/), and the [UGC Creator Agreement](agreement.md). Submitting through Workshop grants the Project Owner the non-exclusive official-distribution license described in the Creator Agreement and confirms your rights warranty.

## Create and upload

1. Open the UGC Tool's **Workshop** tab and create or select an item.
2. Use **Set Info** to review its title, description, visibility, and preview image.
3. Choose **Upload**, then select the built `<PluginName>.BBQPlugin`.
4. Confirm the selected file is inside `BBQ/Build/<PluginName>` so its complete containing directory is uploaded.
5. Start the upload and wait for the success message.
6. Open the Workshop page and review the result.

## Validate the delivered copy

1. Subscribe to the private item and wait for Steam to finish downloading.
2. Remove or relocate the local Mods copy with the same identity.
3. Start BBQ Player and open **Mods & UGC > Workshop**.
4. Download if needed, enable the item, and repeat the full content test.
5. Restart once more and confirm it remains healthy.

Only broaden visibility after the Workshop-delivered copy passes. For an update, upload to the existing item and preserve the project identity.
