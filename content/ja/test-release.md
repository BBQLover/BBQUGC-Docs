# テストとリリース

ビルド済みパッケージを公開版 BBQ Player でテストします。Editor プレビューでは、起動時ロード、
Cook 保持、保存済みプリセットの復元、アクティブなカスタムルートからの切り替えを確認できません。

## ローカルテスト

1. BBQ Player を終了します。
2. ビルド済みパッケージディレクトリ全体を Player のローカル Mods ディレクトリへコピーします。
3. Player を通常の方法で起動します。
4. パッケージ管理画面でローカルパッケージを見つけ、有効にします。
5. クリーンなプロセスから再起動します。
6. Settings を開き、UI プリセット一覧で Definition の **Display Name** を探します。
7. 選択してルートが再構築されることを確認します。
8. もう一度再起動し、選択が復元されることを確認します。

## 機能テスト表

ルートが提供する全機能をテストします。

- 空およびデータありのライブラリ
- 空、1 項目、並べ替え済みの再生キュー
- 再生、一時停止、シーク、前、次、ミュート、音量
- 字幕表示と字幕消去
- ランタイムと前面オーバーレイ
- オーバーレイを消さない HUD 表示切り替え
- 通知、確認、永続表示、自動消去
- 最小化、最大化、復元、安全な終了
- 設定変更と UI プリセットによる復旧
- 失敗または利用不可の API 要求

狭い／通常／広いウィンドウ、複数 DPI、キーボードフォーカス、長い翻訳文、任意画像なし、
モーション軽減設定も確認します。

## 終了処理とフォールバック

1. 標準 UI に戻し、カスタムルートへイベントが届かなくなることを確認します。
2. カスタムルートを再選択し、購読が重複していないことを確認します。
3. パッケージを無効化または削除します。
4. 再起動し、標準ルートへフォールバックすることを確認します。
5. 旧版を入れてから新版へ更新し、選択テストを繰り返します。

## リリースチェックリスト

- [ ] 公開済みの最新 BBQ UGC Tool と必要な Engine バージョンでビルドした。
- [ ] 全アセットを `Content/<PluginName>` 以下に保存した。
- [ ] ルートが `BBQUIRoot` を実装し、表示レイヤーを分離した。
- [ ] ライフサイクルが一度だけ初期化され、全リスナーを解除する。
- [ ] 通知表示を完全実装した、または未設定にした。
- [ ] UI Root Definition の名前が固有で安定し、有効な Root Class がある。
- [ ] Definition が `PluginEntry` の Asset Register List に含まれる。
- [ ] 全コマンドと完了経路が失敗を処理する。
- [ ] 復旧用に標準 UI を選択できる。
- [ ] クリーンインストール、再起動、切り替え、更新、フォールバックを確認した。
- [ ] 競合するローカルパッケージを外して配布版をテストした。
