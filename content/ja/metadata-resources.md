# メタデータとリソース

プロジェクトを選び、**Edit Metadata** でクリエイター向け項目を入力します。ウィンドウを閉じると保存されます。

| 項目 | ガイド |
|---|---|
| `Id` | ツールが作る ID。更新時も保持します。 |
| `Name` | プロジェクトとパッケージ名。固定します。 |
| `Version` | 依存関係の選択に使う数値版。 |
| `VersionName` | `1.0.0` などの表示版。 |
| `FriendlyName` | ユーザーに見える名前。 |
| `Description` | 短いパッケージ説明。 |
| `Category` | 最も近い分類。なければ `Other`。 |
| `CreatedBy` | クリエイターまたはチーム名。 |
| URL 項目 | 公開 HTTPS リンク、または空欄。 |

通常の更新では同じプロジェクト、`Id`、`Name` を維持します。互換性のない別作品にするときだけ新しい ID を作成します。

## 表示リソース

`<ProjectRoot>/BBQ/Resources/` に配置します。

- `Cover.png`: 正方形カバー。500×500 が作業サイズの目安です。
- `Description.png`: 横長画像。1920×1080 が目安です。

ビルダーは物理リソースツリー全体をコピーします。シンボリックリンクを避け、最終パッケージでコピー結果を確認してください。
