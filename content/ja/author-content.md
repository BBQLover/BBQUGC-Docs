# コンテンツ制作

1. プロジェクトを選び **Open Project** を実行します。
2. 制作するアセットはすべて `Content/<PluginName>/` 以下に置きます。
3. 現在のテンプレートが公開する機能でコンテンツを作ります。
4. 全アセットを保存し、参照不足、コンパイルエラー、検証警告を解消します。

Cook の対象はプラグインのコンテンツルートです。エディターで動いても、外部に置いたアセットは省かれる場合があります。エディター専用コンテンツ、ローカル絶対パス、テストアセット、クリエイター向けに提供されていない Player アセットを参照しないでください。

## 任意の UI パッケージ

選択可能な置き換え UI も提供できます。[ルート UI の作成](create-root.md)から始め、[ライフサイクル](lifecycle.md)を実装し、記載された [UI API](apis.md) だけを使用してください。

## Unreal を閉じる前に

- 変更した全アセットを保存する。
- Blueprint をコンパイルしてエラーを解消する。
- 必須参照が対応するクリエイターコンテンツ内にあるか確認する。
- 他のコンテンツから参照される前に名前とパスを確定する。
